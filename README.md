# Shaurya Jauhari — Personal Portfolio

A responsive personal portfolio website built with **HTML, CSS, and vanilla JavaScript**. It presents my education, technical interests, skills, projects, and contact details.

## Sections
- Home
- About Me
- Skills
- Projects
- Contact

## Run locally
No build tools or dependencies are required.

1. Download or clone this repository.
2. Open `index.html` in a modern browser.

## Customize before publishing
Open `index.html` and update:
- `YOUR_EMAIL@example.com` with your real email address (both the contact link and `mailto:` form handler).
- `YOUR-LINKEDIN` with your LinkedIn profile slug.
- `YOUR-GITHUB` with your GitHub username.
- Education, skills, project descriptions, and location if anything changes.
- Add verified GitHub/demo links to project cards when available.

The contact form uses a `mailto:` link. It opens the visitor's configured email application; it does **not** send messages through a server or store submissions.

## Deploy with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `README.md`, and `audit.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your default branch (usually `main`) and folder `/ (root)`, then save.
6. Wait for the Pages deployment and open the published URL shown in the Pages settings.
